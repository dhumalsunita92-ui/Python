# Python
Book-Scraping-Project
Overview
Book Scrapper is a Python-based web scraping project that extracts book information from an online bookstore website. The scraped data is cleaned, structured, and exported into a CSV file for further analysis.

This project demonstrates practical skills in web scraping, HTML parsing, data collection, and data processing using Python.

#######  Project Objectives
Extract book details from a website.
Collect product information automatically.
Store scraped data in a structured format.
Export data to CSV for analysis and reporting.

########## Technologies Used
1) Python
2) Requests
3) BeautifulSoup (bs4)
4) Pandas

####### Features
1) Extract Book Titles
2) Extract Book Prices
3) Extract Book Ratings
4) Extract Availability Status
5) Store Data in CSV Format
6) Data Cleaning using Pandas

############ Workflow
1) Send a request to the target website.
2) Retrieve the webpage HTML content.
3) Parse HTML using BeautifulSoup.
4) Extract required book information.
5) Create a Pandas DataFrame.
6) Save the extracted data into a CSV file.

######## How to Run
Open:
1) bookscrapper.ipynb
2) Run all cells to scrape data and generate the output CSV file.
